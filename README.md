# Фокус · проверка промпта продавца

Мини-приложение для ДЗ PRO-3 по автопромптингу. На одном экране доступны три сценария, обе версии промпта, шесть реплик каждого сохранённого диалога и оценки Sol с цитатами.

## Запуск

Нужен Node.js 22 или новее. Из папки проекта выполните:

```sh
npm start
```

Откройте [локальное приложение](http://127.0.0.1:4173). Сохранённые результаты доступны сразу. Кнопка «Запустить в OpenAI» появляется, когда сервер получает `OPENAI_API_KEY` из окружения или локального файла `.env.local`. Новый прогон отображается до перезагрузки страницы. Сравнение в верхней части экрана использует сохранённые результаты отчёта.

## Как устроен эксперимент

- [Архив прогонов с Sol 6.2](data/experiment.json) содержит сценарии, критерии, оба промпта, пять новых диалогов, оценки и переоценку первого эксперимента.
- [Архив с Sol 5.6](data/experiment-sol-5.6.json) содержит диалоги и оценки первого эксперимента, использованные для сравнения.
- [Сценарий эксперимента](scripts/experiment.mjs) показывает порядок вызовов и фиксацию итогового промпта до проверки третьего сценария.
- [Логика ролей](lab.mjs) использует `gpt-5.6-terra` для реплик клиента, `gpt-5.6-luna` для продавца и `gpt-6.2-sol` для отдельных запросов оценки и оптимизации. Исходные материалы подготовила `gpt-5.6-terra` в первом эксперименте. Факты о курсах передаются продавцу отдельно от системного промпта.
- Ключ читает сервер. В браузер передаётся только признак настройки. HTTP-сервер слушает локальный адрес, а API принимает запросы на запуск с того же адреса приложения.

В работе используются [Responses API](https://developers.openai.com/api/reference/resources/responses/methods/create) и [структурированные ответы](https://developers.openai.com/api/docs/guides/structured-outputs).

## Публичная версия

Команда `npm run build` собирает интерфейс в `dist/`. Vercel Functions отдают архив и запускают новые прогоны для сохранённых сценариев. Для запуска требуется серверная переменная `OPENAI_API_KEY`. Необязательная переменная `OPENAI_RUNS_UNTIL` задаёт срок доступности запусков в формате ISO 8601. Архив остаётся доступным после этого срока.

[Отчёт ДЗ PRO-3](<output/pdf/ДЗ PRO-3 — Автопромптинг.pdf>) содержит промпты, сравнение оценщиков и скриншоты. Шрифт [Onest](https://github.com/googlefonts/onest) распространяется по [SIL Open Font License](public/ONEST-OFL.txt).
